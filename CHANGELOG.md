# Version 1.3.0

## New Features

### Version Support
**New version support: 1.21.5 Fabric and NeoForge**

### Token Configuration Options
Added options to configure normal tokens:
- Increase or decrease the maximum number of normal tokens
- Increase or decrease the recharge time for tokens

*Note: Changes are planned for the guaranteed token, so it will remain unchangeable for now.*

### New Collections
- **DOOM** - New figure collection added
- **The Amazing Digital Circus** - New figure collection added

## Bug Fixes

- **Fixed background rendering bug in Settings modal** (1.21.X versions)
- **Fixed z-index issue where figures appeared above Settings modal**
  - 3D figures no longer render when Settings modal is open
  - Figure name labels are now hidden when modal is active
  - Question marks for undiscovered figures no longer overlap the modal
